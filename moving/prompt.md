# 프롬프트
웹페이지에서 아파트 내부를 3d로 구성해서 언제든 내가 쉽게 볼수 있게 구성해줘 게임처럼 앞뒤로 움직이고 위아래로 돌려보고 줌인아웃이 모두 됐으면 좋겠어. Html 파일로 구성해서 다운받고 싶어. 또한 책상, 수납장, 침대등 사이즈 넣으면 배치도 할수 있는 배치모드가 있으면 좋겠어.
모바일에서도 보기 쉬워야하고 이동이나 이런게 가능해야해.
도면은 내가준 이미지와 영상을 확인하고 예시는 맨 마지막 영상에 같이 넣었어(1인칭 보기 모드야)
모드는 1인칭 보기 모드와 2d조감도, 3d조감도 모드 세개가 있어야ㅎ3d조감도는 카메라 이동이 있고 2d 는 카메라이 고정. 줌인아웃만 있어
가구 배치도 삭제도 쉽고 삽입도 쉬워여하고 삽입할때 사이즈 도 넣게 해줘
가구 배치시 다른 가구랑 겹치거나 문열림이 불가능 하거나 벽체랑 겹치는 등 충돌검사해서 배치 불가능한 경우 오브젝트에 빨간색으로 칠하고 배치가 안되도록 하고 이유도 출력해줘야해.
가구 사진은 냉장고 김치냉장고 세탁기 건조기 침대 책상 의자 식탁 등은 기본으로 넣어줘 대신 사이즈를 결정하게.
파일의 결과물은 다운로드 받을수 있게 html 파일로 해줘 대화창에 넣으면 보기 힘들어
