호스팅 서비스는 무료 플랜의 사용 한도 및 정책이 적용됩니다.

GitHub Pages 배포 방법

별도의 서버나 빌드 없이 HTML 호스팅하기

  1. GitHub 가입 및 로그인GitHub 계정을 준비합니다.
  2. 저장소 만들기New repository에서 이름을 사용자이름.github.io로 지정하고 Public을 선택한 뒤 생성합니다. 이미 같은 이름이 있다면 다른 프로젝트 저장소를 사용해도 됩니다.
  3. HTML 파일 업로드Add file → Upload files를 누르고 파일 4개를 같은 폴더에 올린 후 Commit changes를 누릅니다.
    index.html
example.html
result1.html
result2.html
  4. GitHub Pages 활성화Settings → Pages의 Source에서 Deploy from a branch를 선택합니다. Branch는 main, 폴더는 /(root)로 지정하고 Save를 누릅니다.
  5. 공개 URL 확인배포가 완료되면 Pages 설정에서 사이트 주소를 확인합니다. 사용자 사이트 주소는 https://사용자이름.github.io/이며, 프로젝트 저장소는 https://사용자이름.github.io/저장소이름/ 형태입니다.

GitHub Free에서는 공개 저장소로 Pages를 이용할 수 있습니다. 사이트와 파일이 공개되므로 개인정보, 주소가 포함된 평면도, 비밀번호 등은 업로드 전에 확인하세요.
